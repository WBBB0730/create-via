# 0003 项目名没有默认值，浅色提示显示模板仓库名

## 背景

多数建项目工具会给项目名一个回车即用的默认值。但 create-via 面对的模板各有各的命名规范，比如 web 项目和游戏项目的命名习惯就不一样。

## 决定

交互询问**项目名**时，浅色提示（placeholder）显示**模板仓库**的名字，但它不是默认值，必须自己填。留空会提示「请输入项目名」。

## 理由

模板仓库的名字本身就是那套命名规范的示范，放在提示里，使用者可以照着写。但如果回车就能用，很容易把新项目建成模板的名字。

## 后果

- 交互模式下每次都要手动输入项目名。命令行带了项目名参数时不再询问。

## 被否的方案

- **把模板仓库名设成回车即用的默认值**：容易把新项目建成模板的名字。
- **按模板仓库名的大小写风格推断默认名**：主流工具都不这么做，而且容易猜错。
